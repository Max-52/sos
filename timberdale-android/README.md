# Timberdale — Android-проект (соберёт APK сам)

На компьютере ничего ставить не нужно: APK соберёт бесплатный сервис GitHub Actions.

1. Зарегистрируйся на github.com и создай новый репозиторий (кнопка New).
2. Загрузи туда ВСЁ содержимое этой папки (Add file → Upload files). Папка `.github` — скрытая; если её не видно или она не загрузилась, нажми Add file → Create new file, впиши путь `.github/workflows/build-apk.yml` и вставь в него текст из файла `build-apk.yml.backup`.
3. Открой вкладку Actions → Build APK → Run workflow (или просто дождись автозапуска после загрузки).
4. Через 3–6 минут зайди в готовый запуск и в разделе Artifacts скачай `Timberdale-APK` (внутри zip лежит app-debug.apk).
5. Скинь APK на телефон и открой. Android попросит разрешить установку из этого источника — разреши.

Игра лежит в `app/src/main/assets/index.html`. Если захочешь обновить игру — замени этот файл и снова загрузи на GitHub.
Приложение полноэкранное, горизонтальное, работает без интернета.
